# OnlyNote

Минималистичные заметки на Android: два экрана, простой текст, ни аккаунта, ни сети.

Kotlin · Jetpack Compose · minSdk 26 · только arm64 · без интернета и без разрешений
(кроме записи в «Документы» на Android ≤ 9).

## Что нового в 1.2

- **Отмена и возврат по словам**, как в ColorNote: шаг истории — слово, а не
  отрезок времени; пробел уходит вместе со своим словом.
- **Меню цветов без галочки**: выбранная плитка ничем не помечена.
- **Вес APK: 1,11 МБ** вместо 1,37 МБ. Ужаты шрифты, отсечены чужие языки,
  включён полный режим R8, убрана лишняя иконка и мёртвый код.
- **Только 64-битные устройства** (arm64-v8a); поддержка Android 6–7 и 32-битных
  процессоров убрана.
- Выделение текста больше не пытается прокручивать: выделяется то, что видно.

## Как пользоваться

Всё управление — жестами, кнопок на экране нет.

### Главный экран

Экранов два: **рабочий** и **архив**. Категория у заметки одна — цвет; цветная
полоска слева и есть эта категория, по ней же заметку переносят с экрана на экран.

| Жест | Что делает |
| --- | --- |
| **Свайп по горизонтали** | переход между рабочим экраном и архивом (архив приезжает слева) |
| **Долгое нажатие по пустому месту** | новая заметка — на том экране, где нажали |
| **Короткое нажатие по заметке** | открыть её |
| **Долгое нажатие по полоске** | перенести заметку на другой экран |
| **Долгое нажатие по самой строке** | удалить (с подтверждением) |
| **Нажатие по надписи OnlyNote** | резервные копии: экспорт, импорт, автоматическая копия |

Пустое место в конце списка есть всегда, даже когда заметок много: последняя
полоса экрана под списком — та же «новая заметка».

### Заметка

| Жест | Что делает |
| --- | --- |
| **Нажатие по тексту** | начать правку в этом месте |
| **Нажатие по шапке** | правка с курсором в конце заметки |
| **Долгое нажатие по левой половине шапки** | цвет заметки (работает в просмотре) |
| **Долгое нажатие по правой половине шапки** | поиск по заметке (работает в просмотре) |
| **Нажатие по левой половине шапки в правке** | отменить последнюю правку |
| **Нажатие по правой половине шапки в правке** | повторить отменённую |
| **Системный «назад»** | из правки — в просмотр, из просмотра — к списку |

В просмотре клавиатуры нет, но текст можно выделить и скопировать: выделение
системное, ручки тянутся, у края экрана текст прокручивается за пальцем.
Заметка пустая — она не сохраняется: вышли, и её нет.

### Что внутри

- **Одна заметка — одно поле.** Не список блоков, а нативный `EditText` на всю
  заметку: потолок 150 000 знаков, выделение, ручки и «Выбрать всё» — системные
  и работают через всю заметку.
- **Только простой текст.** Вставка из буфера очищается от чужой разметки.
- **Поиск внутри заметки** с подсветкой совпадений и счётчиком «1/24».
- **Отмена и повтор** по словам: шаг — слово целиком, разделитель закрывает шаг.
- **Восемь цветов.** Цвет живёт в шапке, разделителе, полоске и тексте, а не в фоне.
- **Резервные копии.** Автоматическая копия раз в день внутри приложения плюс
  экспорт в JSON в «Документы»; хранятся четыре последних выгрузки.
- **Ни сети, ни аккаунта.** Всё лежит в одном файле рядом с приложением.

## Дизайн

Всё построено на нескольких числах, и каждое проверено замером на телефоне,
а не на глаз: чёрный `#000000`, текст `#BEBEBE`, второстепенное `#727272`,
ни одного скругления и ни одной волны под пальцем, один шрифт (Rubik) с двумя
начертаниями, названия заметок — 18 sp Regular, надпись приложения — 22 sp
SemiBold, кегль текста заметки 16 sp с межстрочным 130 %.

## Сборка

Нужны JDK 17 и Android SDK 35 (`compileSdk = 35`).

```
./gradlew assembleDebug
```

Release собирается неподписанным, если нет ключа: положите его в
`keystore/debug.keystore` и задайте `ONLYNOTE_STORE_PASSWORD`,
`ONLYNOTE_KEY_ALIAS`, `ONLYNOTE_KEY_PASSWORD` — тогда APK подпишется
(см. `app/build.gradle.kts`).

Тесты: `./gradlew testDebugUnitTest` (19 тестов — порядок заметок, цвета, разбор
резервных копий, поиск, история правок).
