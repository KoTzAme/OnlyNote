# OnlyNote

Минималистичные заметки на Android: один экран, простой текст, ни аккаунта, ни сети.

Kotlin · Jetpack Compose · minSdk 26 · без интернета и без разрешений
(кроме записи в «Документы» на Android ≤ 9).

## Что это

- **Папки и заметки в одном списке.** Нажатие на папку разворачивает её заметки
  под ней, повторное — сворачивает. Никаких вложенных экранов.
- **Одна заметка — одно поле.** Не список блоков, а нативный `EditText` на всю
  заметку: потолок 150 000 знаков, выделение, ручки и «Выбрать всё» — системные
  и работают через всю заметку.
- **Два режима.** Просмотр (без клавиатуры, но текст можно выделить) и правка
  (свой мигающий курсор, без панели форматирования).
- **Только простой текст.** Вставка из буфера очищается от чужой разметки.
- **Поиск внутри заметки** с подсветкой совпадений и счётчиком «1/24».
- **Отмена и повтор** с объединением подряд идущих правок.
- **Восемь цветов.** Цвет живёт в шапке, разделителе и тексте, а не в фоне.
- **Резервные копии.** Автоматическая копия раз в день внутри приложения плюс
  экспорт в JSON в «Документы»; хранятся четыре последних выгрузки.
- **Ни сети, ни аккаунта.** Всё лежит в одном файле рядом с приложением.

## Дизайн

Всё построено на нескольких числах, и каждое проверено замером на телефоне,
а не на глаз: чёрный `#000000`, текст `#BEBEBE`, второстепенное `#727272`,
ни одного скругления и ни одной волны под пальцем, один шрифт (Rubik) с двумя
начертаниями, один шаг 6 dp, кегль текста 16 sp с межстрочным 130 %.

## Сборка

Нужны JDK 17 и Android SDK 35 (`compileSdk = 35`).

```
./gradlew assembleDebug
```

Release собирается неподписанным: положите ключ и задайте переменные окружения
`ONLYNOTE_KEYSTORE`, `ONLYNOTE_STORE_PASSWORD`, `ONLYNOTE_KEY_ALIAS`,
`ONLYNOTE_KEY_PASSWORD` — тогда APK подпишется (см. `app/build.gradle.kts`).

Тесты: `./gradlew testDebugUnitTest` (12 тестов — порядок заметок и поиск).
